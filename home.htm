Sobre o Projeto

NutriHealth é um sistema web desenvolvido para facilitar o acompanhamento nutricional, oferecendo uma plataforma intuitiva e acessível para nutricionistas e pacientes. Integrando tecnologia e usabilidade, o projeto promove organização, praticidade e apoio ao autocuidado alimentar.
